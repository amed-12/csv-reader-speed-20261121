A dependency-free CSV parser that matches the competition's reference, including its handling of malformed quotes, mixed line endings, and uneven row widths.

## Run it

Use Node.js 22.18 or later. The official kit's practice directory contains the input and expected output.

```sh
mkdir -p out
MAKEFUN_INPUT_DIR=/path/to/kit/practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```

The result is written to `out/answers.json`.
